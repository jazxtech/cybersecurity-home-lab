# cybersecurity-home-lab
Project Objective: Personal academic project to build a simulated enterprise security environment to apply cybersecurity concepts and gain practical knowledge.

## Learning Path

### Phase 1: Learning the Foundations
Course:
- TryHackMe Pre Security Room

Topics:
- Networking fundamentals
- Linux basics
- Web fundamentals
- Cybersecurity concepts


### Phase 2: Learning the Core of Cybersecurity
Course:
- TryHackMe Cyber Security 101 Room

Topics:
- Windows fundamentals
- Linux administration
- Authentication
- Security principles
- Defensive security


### Phase 3: Learning Specialized Skills to Create a Home Lab

Courses/Modules:
- TryHackMe Attacktive Directory (Public Room)
- Cisco Networking Basics Course + others
- TryHackMe SOC Level 1 modules

Topics:
- Domain controllers
- Users and groups
- Group Policy
- Enterprise authentication
- SIEM
- Log analysis

## Final Project

Simulated Enterprise Security Environment

Planned implementation:

- Virtual machines
- Windows Server
- Active Directory Domain Services
- Windows client
- Ubuntu Linux
- SIEM platform (Wazuh)

Goal:
Apply cybersecurity knowledge by designing, configuring, and monitoring a small enterprise network.
